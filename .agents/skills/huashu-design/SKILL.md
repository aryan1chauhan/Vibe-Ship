# Huashu Design Philosophy

1. **HTML-Native Prototyping**: Leverage semantic HTML structure with rich CSS custom properties.
2. **Micro-Animations**: Add subtle CSS transitions (`transition: all 0.2s ease-in-out`) and Framer Motion micro-interactions.
3. **5D Design Review**: Evaluate Contrast, Balance, Typography, Responsiveness, and Interactivity on every UI pass.
