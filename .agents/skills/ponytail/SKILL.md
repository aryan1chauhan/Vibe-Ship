# Ponytail Skill

## Rules of Engagement
1. **Minimal Diff Principle**: Make the smallest possible change that meets the exact requirement.
2. **Native First**: Prefer standard language runtime features and framework primitives over introducing new external dependencies.
3. **Zero Over-engineering**: Avoid abstracting code prematurely. Write clear, explicit, readable code.
4. **Targeted Fixes**: Resolve root causes directly rather than adding wrapper layers or fallback hacks.
