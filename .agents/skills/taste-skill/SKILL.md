# Taste Skill

1. **Anti-Generic UI**: Avoid generic corporate blues and default grey cards. Use curated color themes and deliberate layout grids.
2. **Intentional Typography**: Pair display serif or futuristic sans-serif headers with clean body copy.
3. **Pacing & White Space**: Allow elements room to breathe with high visual hierarchy and clean padding.
